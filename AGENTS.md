# Agent guide for HupSup POS

> This file replaces the create-next-app default and is the canonical guide for
> AI agents (Devin, Cursor, Claude Code, Copilot) working in this repo.

## Stack at a glance

- **Next.js 16** (App Router) + React 19 + TypeScript
- **Tailwind v4** + shadcn/ui (added per-component as needed)
- **Drizzle ORM** + **PostgreSQL** (self-hosted via Docker)
- **Auth.js v5** (Credentials provider, JWT sessions)
- **next-intl** for i18n (locales: `th`, `lo`, `en` — default `th`)
- **Self-hostable on any VPS** — no Vercel / Supabase / paid SaaS

## Important Next.js 16 conventions

This is **NOT** the Next.js you may know from training data. Read
`node_modules/next/dist/docs/` for the relevant API before writing route code.

Key differences:

- **`middleware.ts` is renamed to `proxy.ts`** (we use `src/proxy.ts`).
- App Router uses **React 19 canary** with built-in Server Components.
- Routes that depend on the locale must go under `src/app/[locale]/...`.
- Use `setRequestLocale(locale)` at the top of any server component that
  consumes translations to keep static rendering working.

## Running CI checks locally

Before pushing:

```bash
pnpm format:check
pnpm lint
pnpm typecheck
pnpm build
```

The same four commands run in `.github/workflows/ci.yml`.

## DB workflow

1. Edit `src/db/schema.ts`.
2. `pnpm db:generate` — produces a SQL file in `drizzle/`.
3. Review the generated SQL.
4. `pnpm db:migrate` — applies it to local Postgres.
5. Commit both schema and migration files together.

Never edit a migration file after it has been merged. Add a new one instead.

## i18n

Every user-facing string must come from `messages/<locale>.json`. Keys are
namespaced (e.g. `Nav.signIn`). When adding a key, update **all three locale
files** so we don't ship missing translations. Lao translations may start as a
copy of Thai if a native speaker isn't available — flag with a `// TODO(lo)`
comment.

## Money

Always store amounts as `numeric(18,4)` or as integer minor units. **Never use
JS floating-point numbers for money.** Currency is tracked per-transaction
(LAK base, THB accepted with daily rate).

## Commit style

- Branch: `devin/<timestamp>-<short-slug>` (auto-generated by Devin).
- Messages: imperative mood, scoped prefix when useful (`db:`, `i18n:`, `auth:`).
- Keep PRs focused — one sprint slice per PR.

## Things to NOT do

- ❌ Don't add Vercel-specific deps (we self-host).
- ❌ Don't add Supabase or third-party auth SaaS.
- ❌ Don't use `Date.now()` for IDs — use `uuid().defaultRandom()` from Drizzle.
- ❌ Don't store `org_id`-less tables. Multi-tenancy isolation depends on it.
- ❌ Don't use `any`, `getattr`-style access, or non-null assertions to
  shortcut typing — fix the types instead.
